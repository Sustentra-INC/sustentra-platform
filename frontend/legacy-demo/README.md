# Legacy Demo Frontend

This directory preserves the pre-S1 demo/pilot frontend surface. It is kept for
reference only and should not be extended for the Subsystem 1 workpaper UI.

The code here includes the old route pages and demo components that used
placeholder IDs such as `doc_demo_001` and `eng_demo_001`.

New Subsystem 1 work should live in `frontend/features/s1/` and should consume
the current backend through explicit S1 adapters/view models.
