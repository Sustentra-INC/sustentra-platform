# design-reference

Reference material for the Sustentra UI redesign (Linear project: Product UIUX). Not shipped code.

- `screens/` Screenshots of every redesigned screen. Look at these to see the target.
- `source/` The design's HTML source with inline styles. Read these for exact sizes, colors, spacing and icon SVG paths. They are mockups with sample data: copy styling, never copy data or logic.
- `tokens.md` Colors, radius, shadows, spacing and type pulled from the source.

Rules: UI only. Keep every existing flow, field, route and behavior. Match the look, not the mock data.
